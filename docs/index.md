ADBAN は、ウェブサイトの広告とトラッカーをブロックする Chrome / Edge 拡張機能です。このページは、使い方・よくある質問・不具合の報告のしかたをまとめた、利用者向けのサポートページです。

## できること・できないこと

### できること

- **通信の遮断** — 広告配信やトラッカーのサーバーへの通信を、ブラウザーの仕組み（`declarativeNetRequest`）で止めます。
- **広告枠を隠す** — 通信を止めても残る広告の枠を隠します。後から差し込まれる広告にも効きます。
- **ポップアップ広告を閉じる** — 広告のために開かれる新しいタブを閉じます。ログイン・決済などの正規のポップアップは閉じないようにしています。
- **空の広告枠と記事広告をたたむ** — 広告の中身が消えたあとに「広告」の札だけが残った枠や、「PR」「広告」などの表記がある記事広告のカードをたたみます。
- **YouTube・Prime Video** — 広告の情報を取り除き、それでも流れた広告は、ミュートして早送りします。
- **広告ブロッカー対策への対策** — 「広告ブロッカーを無効にしてください」と表示して閲覧を止めるサイトに対処します。
- **要素を選んでブロック** — 残っている広告をクリックで選んで隠せます。
- **サイトごとのオン・オフ**、**自分で書くフィルター**（Adblock Plus と同じ書き方）。

### できないこと

どの広告ブロッカーにも限界があり、すべての広告を必ず消せるわけではありません。

- **サイト自身が配信する広告**（記事と同じサーバーから届く記事広告など）は、通信では見分けられません。「PR」「広告」などの札が付いたものは隠しますが、札のないものは残ることがあります。
- **YouTube・Prime Video** は、広告の出し方を頻繁に変えます。今日効いても、仕様変更で効かなくなることがあります。
- **広告ブロッカー対策のあるサイト** は、対策できるのは主にフィルターリストに載っているサイトです。載っていないサイトでは、警告が出ることがあります。
- **有料会員向けの制限**（記事の有料部分など）は解除しません。
- **Manifest V3 の制約**で、通信の中身を書き換えるような高度な処理（uBlock Origin の一部の機能など）は使えません。

## インストール

### ストア版

Chrome ウェブストア、または Microsoft Edge アドオンで「ADBAN」を探してインストールします（公開後のリンクは、このリポジトリの [README](https://github.com/matsuokamatsuo1919-lang/adban) をご覧ください）。インストールしたら、ツールバーのパズルのアイコンから ADBAN をピン留めすると、ブロック件数が見えて便利です。

### ソースから

1. [リポジトリ](https://github.com/matsuokamatsuo1919-lang/adban)の「Code」から ZIP をダウンロードして展開するか、`git clone` します。
2. Chrome で `chrome://extensions`（Edge なら `edge://extensions`）を開き、**デベロッパー モード**をオンにします。
3. **パッケージ化されていない拡張機能を読み込む** を押し、展開したフォルダーを選びます。

## よくある質問

### 広告が残っています

1. ページを再読み込みしてみてください。
2. **要素を選んでブロック** を使うと、残っている広告をクリックで選んで隠せます（下の項目）。
3. 広告が残るサイトは、[Issues](https://github.com/matsuokamatsuo1919-lang/adban/issues/new?template=ad-remains.yml) から教えてください。サイトのドメインがあれば十分です。
4. サイト自身が配信する広告（記事広告など）は、通信では見分けられないため、残ることがあります。

### サイトが壊れました（表示されない・動かない・崩れる）

ADBAN のアイコンを押して、**このサイトでブロックする** をオフにし、ページを再読み込みしてください。これで直るなら、ADBAN が普通の部分まで止めています。[Issues](https://github.com/matsuokamatsuo1919-lang/adban/issues/new?template=site-broken.yml) から教えてください。直らない場合は、右上のスイッチで全体をオフにして試してください。

### このサイトだけオフにするには

ポップアップの **このサイトでブロックする** をオフにします。もう一度オンにすれば、ブロックを再開します。設定画面の「ブロックしないサイト」で、一覧を見たり、ドメインを足したり外したりもできます。

### 要素を選んでブロックするには

1. ポップアップの **要素を選んでブロック** を押します。
2. ページ上の消したい広告をクリックして選びます。**親要素へ** で範囲を広げられます。
3. **ブロック** を押すと保存され、そのサイトで隠れます。画面を覆う警告を選んだときは、止められていたスクロールも元に戻します。

選んだものは、設定画面の「自分で書くフィルター」で見たり消したりできます。

### 自分で書くフィルターとは

設定画面で、Adblock Plus と同じ書き方のフィルターを自分で書けます。たとえば `example.com##.ad-banner` と書くと、example.com の `.ad-banner` を隠します。書き方の例は、設定画面の説明をご覧ください。なお、`+js(...)`（スクリプレット）は、同梱のリストに入っているものだけが使えます。

### YouTube で広告が流れます

YouTube は広告の出し方を頻繁に変えるため、効かなくなることがあります。ADBAN は、動画の広告の情報を取り除き、それでも流れた広告は、ミュートして早送り・スキップします。設定画面の「動画の広告データを取り除く」をオフにすると、YouTube 側の警告が出にくくなる場合があります。ずっと効かない場合は、[Issues](https://github.com/matsuokamatsuo1919-lang/adban/issues/new?template=ad-remains.yml) に、いつからか、ブラウザーの種類と版を書いて教えてください。

### Prime Video で広告が流れます

Amazon も広告の出し方をよく変えます。ADBAN は、広告の区間を消すルールと、それでも流れた広告の早送り（ミュートしたまま速く流す）で対処します。広告の本数ぶんの時間はかかることがあります。止まらないときは、設定画面の「Prime Video の診断」を自分でオンにして、広告が流れる様子を記録できます。診断は、**自動では送られません**。「診断をコピー」で自分でコピーして、Issues に貼り付けた場合だけ、開発者に届きます。作品名やアカウント情報は記録しません。

### ポップアップ広告（新しいタブで開く広告）が閉じません

ADBAN は、フィルターリストの `$popup` に当てはまるものだけを閉じます。ログイン・決済などの正規のポップアップを巻き込まないためです。閉じないポップアップのサイトは、[Issues](https://github.com/matsuokamatsuo1919-lang/adban/issues/new?template=ad-remains.yml) で教えてください。

### 設定のしかた

ポップアップの **設定** から、設定画面を開きます。使うフィルターリストの選択、YouTube の設定、ブロックしないサイト、自分で書くフィルターを変えられます。

## 不具合の報告のしかた

不具合の報告・ご意見・ご要望は、[Issues](https://github.com/matsuokamatsuo1919-lang/adban/issues/new/choose) で受け付けています（GitHub のアカウントが必要です。作りたくない場合は、メールでも構いません）。

拡張機能の ADBAN のアイコンを押すと、下に **問題を報告** があります。種類を選ぶと、報告に役立つ情報（ADBAN の版、ブラウザーの種類と版、OS の名前、設定のオン・オフ、今のサイトのホスト名、止めた件数など）がコピーされます。「サポートのページを開く」を押して、Issues のフォームにコピーした内容を貼り付けます。**自動では何も送られません。** 貼り付ける前に、内容を確認・編集できます。

**書いてはいけないもの**: 名前、メールアドレス、パスワード、住所、閲覧履歴、アカウント情報。Issues は誰でも読める公開の場所です。サイトの情報は、ドメインだけで足ります。

返信は、数日以内を目標にしています（確約はできません）。詳しくは [SUPPORT.md](https://github.com/matsuokamatsuo1919-lang/adban/blob/main/SUPPORT.md) をご覧ください。

## プライバシー

ADBAN は、利用者の個人情報・閲覧履歴・ページの内容を**収集しません**。開発者や第三者のサーバーへ、データを**送信しません**。設定は、利用者のブラウザーの中だけに保存されます。詳しくは、[プライバシーポリシー]({{ '/privacy' | relative_url }})をご覧ください。
